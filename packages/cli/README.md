## Installation

```
npm i -g kannada-script
```

## Usage

Create a file, for example `hello.kans`:

```
namaskara
  idu hesaru = kelu("Ninna hesaru? ");
  helu "Namaskara " + hesaru + "!";
matte sigona
```

Run it:

```
kannadascript hello.kans
```

Keywords can also be written in Kannada script (ನಮಸ್ಕಾರ, ಹೇಳು, ಇದು …). See the
[documentation](https://kannadascript.netlify.app/#docs) for everything the
language supports, or try it without installing in the
[playground](https://kannadascript.netlify.app/playground).
